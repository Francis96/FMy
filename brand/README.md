# MOANETU · Identité visuelle v1

**La foi, du lundi au samedi.** Animation 3D (9:16) sur la vie chrétienne au quotidien.

Guide complet : `moanetu-brand.html` (à ouvrir dans un navigateur).

## Le symbole
Une bulle de parole qui fait le « regard en coin » : paupière mi-close, un sourcil levé, pupilles tournées vers la droite. Un petit reflet en croix dans chaque pupille.

## Couleurs
| Nom | Hex | Usage |
|---|---|---|
| Bleu uniforme | `#2747D6` | Signature, fonds, logo (40 %) |
| Blanc de chaux | `#F3ECE1` | Fond clair, logo inversé (25 %) |
| Brun cacao | `#3A2215` | Texte, contours, pupilles (15 %) |
| Ocre mur | `#D99A4E` | Décors, chaleur (8 %) |
| Turquoise wax | `#7CCFC6` | Secondaire (7 %) |
| Rouge pagne | `#E0402F` | Action, mot-clé (5 % max) |
| Ciel de midi | `#8CC6EC` | Fonds de scène |

## Polices (Google Fonts, gratuites)
- **Bricolage Grotesque ExtraBold** : nom, titres, sous-titres vidéo, miniatures
- **Instrument Sans** : textes longs, descriptions
- **DM Mono** : numéros d'épisode, dates, versets

## Fichiers (`logo/`)
| Fichier | Usage |
|---|---|
| `moanetu-photo-profil.png` | Photo de profil TikTok / YouTube / Instagram |
| `moanetu-filigrane-video.png` | Filigrane en haut à gauche de chaque vidéo (14 % de la largeur, opacité 90 %) |
| `moanetu-logo-horizontal-couleur.png` | Sur fond clair |
| `moanetu-logo-horizontal-blanc.png` | Sur fond cobalt ou foncé |
| `moanetu-symbole-*.svg/png` | Symbole seul : couleur, inversé, une couleur (cacao) |

## Dans chaque vidéo
1. **Ouverture (1,2 s)** : la bulle apparaît avec un rebond, cligne, puis le nom monte. Son : deux notes de balafon et un « hmm ».
2. **Filigrane** : en haut à gauche pendant toute la vidéo.
3. **Sous-titres** : Bricolage ExtraBold blanc, contour cacao, un mot-clé par phrase en pastille cobalt, à 60 % de la hauteur.
4. **Carte de fin (2 s)** : fond chaux, une question pour lancer les commentaires, bouton « Abonne-toi » rouge pagne, date du prochain épisode.
